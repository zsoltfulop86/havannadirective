Anonymous telemetry

What is sent

SS: Zombie Rain submits an anonymous event when the player dies: a random event ID, difficulty, game build version, and event time. The game does not submit player names, account IDs, or platform identifiers. Cloudflare necessarily processes the requesting IP address to deliver, rate-limit, and protect the service; Havanna Directive does not write IP addresses to the death-event database.
